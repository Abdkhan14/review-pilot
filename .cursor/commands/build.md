# Build

Follow the project Next.js build skill.

1. Read `.cursor/skills/nextjs-build/SKILL.md` and obey the build loop and self-check.
2. Read `.cursor/skills/nextjs-build/recipes.md` before writing App Router pages, routes, or `proxy.ts`.
3. Read `.cursor/skills/nextjs-build/testing.md` before writing tests.
4. Read `.cursor/skills/nextjs-build/examples.md` and clone that shape (intent → files → test first → smallest implementation → stop).

Do not invent a parallel folder tree. One behavior per change.
